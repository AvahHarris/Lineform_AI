# Update notes – 2026-11-21

GUI only. No firmware upload needed.

## Save / Load: one file per shape or animation

- Buttons:
  - Row 1: Create Shape | Reset | **Stop Animation**.
  - Row 2: **Save Shape | Load Shape**.
  - Row 3: **Save Animation | Load Animation**.
- Save and Load open the normal file dialogs (Windows / Mac / Linux), starting in `gui/Gui_3_0/shapes/` and `animations/`. Files can be saved and loaded anywhere.
- **Nothing loads at startup, and typing a name in the chat loads nothing.** `shape_library.json` is no longer read; the 10 calibrated presets are now single files in `shapes/`.
- **Shape file:** `"type": "shape"`, name, the 11 angles, Shape Size range (`small` / `large`), `"torque"` and `"stiffness"` (11 each). Rows switched OFF are saved as torque 0. Loading puts it on the bars at exactly the saved pose and applies its torque / stiffness (if the file has them); press Create Shape to send it.
- **Animation file:** Save Animation (while one plays) **records the next 3 s**: every 40 ms, all 11 angles + torque + stiffness. Then it asks where to save. Load Animation plays the 3 s, returns smoothly to the first frame over 0.5 s, then loops until Stop Animation; torque / stiffness follow the recording. The file also keeps the Motion agent's original input (`"source"`) when known.
- Settings in `AnimLibrary.pde`: `ANIM_RECORD_SECONDS` (3), `ANIM_RECORD_INTERVAL_MS` (40), `ANIM_REPLAY_RESET_MS` (500).
- Code: `Files.pde` (dialogs, shape files), `AnimLibrary.pde` (record / replay).

## Loaded shapes / animations: context for both agents

- Loading a shape or animation gives **both** agents a note on their next message: what was loaded, its saved parameters (bends, torque, stiffness, and for animations the original agent input), and that it is what we're working on. So "bigger" / "faster" refer to it.
- Code: `agentsNoteLoadedShape()` / `agentsNoteLoadedAnimation()` in `Agents.pde`.
