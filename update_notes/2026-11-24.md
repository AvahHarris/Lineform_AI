# Update notes – 2026-11-24

GUI only. No firmware upload needed.

## Loaded files

- After Load Shape / Load Animation, the loaded item is the current one for both agents (until a new shape / animation, another load, or Reset). Each message carries its parameters (full the first time, then a short reminder) and tells the agents to adjust it rather than make a new one.
- `adjust_loaded_shape` (Designer): bends, `bend_scale`, torque, stiffness. Loaded animations: `adjust_current_animation` (2026-11-25).
- Files are never modified. Save dialogs always suggest a new name.
- Code: `Loaded.pde`.

## Create Shape starts NEW items only

- Waits for Create Shape: a new animation (agent, Load Animation, prompt box), a newly loaded shape, a new Designer shape or new bends to a loaded shape. Their own torque / stiffness wait with them.
- Everything else is instant and goes to the current item: bars, switches, `set_joint_settings`, torque / stiffness-only adjustments, `adjust_current_animation` on the playing animation.
- Until Create Shape the real arm works as before (live angles, load colors, overload trip).
- A new waiting item replaces the old one; Reset drops it.
- Pinned green READY note in the message corner.
- Ghost preview: translucent green motor blocks (animations loop on it); the solid arm shows the real motors.
- Save Shape / Save Animation always save the current item, never the ghost. Code: `Staging.pde`.
