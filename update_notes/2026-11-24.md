# Update notes – 2026-11-24

GUI only. No firmware upload needed.

## Loaded files stay the current item for both agents

- After **Load Shape / Load Animation**, the loaded item is the current one for both agents. It stays that way until an agent makes a new shape or animation, you load something else, or you press Reset.
- **Every message** to either agent carries a LOADED note:
  - The first time, with the file's full parameters:
    - Shape: every joint's bend, torque and stiffness.
    - Animation: duration and loop, each joint's swing range, keyframes about every 200 ms, torque / stiffness, and the original agent input if saved.
  - After that, a short reminder with the latest values.
- **Rules in the note:**
  - Don't go back to earlier designs or invent a new one.
  - For changes, adjust the loaded item.
  - Make a new one only when the user clearly asks for something different.
  - These rules override "start from your most recent shape / animation".
- **New adjust tools** (only offered while an item is loaded):
  - `adjust_loaded_shape` (shape agent): new joint bends and/or `bend_scale`, torque, stiffness. Applied to the bars; press Create Shape.
  - `adjust_loaded_animation` (animation agent): `speed_factor`, `amplitude_factor` (swing size), torque, stiffness. Applied to the recording itself, which restarts.
- While an animation is loaded, the animation agent no longer sees the shape agent's earlier shape.
- Code: `Loaded.pde` (new); hooks in `Agents.pde`, `Files.pde`, `AnimLibrary.pde`.

## Loaded files are never modified

- Loading only reads a file. All changes (bars, agent adjustments) stay in memory.
- The GUI writes a file only after you pick it in a Save dialog, and the dialog now always suggests a **new** name (`square_2.json`, …), never the file it was loaded from. Overwriting is only possible by picking an existing file yourself, and the system asks first.

## Create Shape starts new items

- New `Staging.pde`. These wait for **Create Shape**:
  - A **new animation**, from the Motion agent, Load Animation or the old prompt box. If another animation is playing, it keeps playing until Create Shape starts the new one.
  - A **newly loaded shape file**: its pose, torque and stiffness all go to the arm on Create Shape. Until then the bars, the solid arm and a playing animation are left alone.
  - A **new pose** from the Designer (or an adjusted loaded shape). It is fitted without touching the bars or a playing animation, shown as the ghost, and put on the bars and sent on Create Shape. Its torque / stiffness stay instant.
- **Everything else is instant, as before:**
  - torque / stiffness changes (bars, agents, Settings Critic);
  - changes to the animation that is playing (`adjust_loaded_animation`).
- A change to an item that is still waiting updates the waiting item. A new waiting item replaces the old one; Reset drops it.
- Save Shape saves a waiting shape (the ghost) if there is one.
- The agents are told this, and the arm-state note shows a waiting item.
- **Ready note:** a pinned green note in the message corner ("READY: … click Create Shape to play it") stays until Create Shape / Reset.
- **Preview:** while something waits (shape or animation), the 3D view draws it as a translucent **green ghost arm** of motor blocks; a waiting animation loops on it. The **solid arm keeps showing the real motors**: live angles, load colors, white load lines and the overload trip all work as normal until Create Shape. Pose animations are solved for the preview without touching the bars, and Create Shape plays exactly those poses.
