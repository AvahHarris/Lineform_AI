## Firmware (`lineform-ai.ino`)

- **Motor order:** `DXL_IDS = {1 … 11}`, base to tip.
- **Angles:** the reverse list and offsets are applied to every goal and reading. Goals stay within the motor's current turn, so no move crosses 0°/360°. Readings are folded into 0–360°. A failed read repeats the last good value.
- **Torque limit:** sets `GOAL_CURRENT` and `GOAL_PWM` via `writeControlTableItem()`; 0% = torque off.
- **Torque-on:** reboots a motor with a hardware error (e.g. overload) to clear it, then re-applies P/I gain, profile and torque limit.
- **Unfitted slots:** slots past `ACTIVE_MOTORS` are ignored on writes and report 180° / 0 load.
- **Status commands (242–247):** motor mode, torque, error, goal PWM/current, last torque command received, command counts.

## GUI (`gui/Gui_3_0/`)

- **Motor numbering:** labels show 1 at the base, using `displayId()`; `hwId()` gives the real ID sent to the motor.
- **Per-motor ON/OFF switch:**
  - OFF goes limp.
  - ON holds the current pose, at the row's torque %.
  - Create Shape turns OFF motors back on.
  - Reset turns everything on.
- **Live angle bars:**
  - The bars always show the real angle.
  - Hand-move detection is separate: once a push exceeds the threshold, the motor holds where it is released.
  - Create Shape sends each motor's target, not the live reading.
  - Bad readings that jump more than 45° are dropped.
- **Torque bars:** the orange bar sets the limit. The white line shows the live load. Text under the bar shows the motor's read-back.
- **Reset:** sends the neutral frame as one atomic serial write, with no extra torque-on burst, then runs diagnostics.
- **Canvas:**
  - Draws the bar values.
  - Unfitted motors are grey and straight.
  - Optional fixed "12" block at the tip, base mount plate, and pivot dot at motor 1.
- **Release motors on exit:** `RELEASE_MOTORS_ON_EXIT = true` turns torque off when the window closes.
- **Diagnostics:** printed to the Processing console only, at startup, after Reset, and ~1 s after a torque change. The live reader retries instead of giving up.
