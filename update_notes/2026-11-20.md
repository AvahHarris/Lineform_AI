# Update notes – 2026-11-20

GUI only. No firmware upload needed.

## Agents

- **Temperature: not sent.** `claude-opus-5` rejects it ("temperature is deprecated").
  - `"agent_temperature"` in `local_config.json` (default -1 = off) can set it for a model that accepts it.
  - If the API rejects it, the GUI drops it for the session and resends the request automatically.
- **Settings Critic** (new): one extra round after each designed shape, only for torque and stiffness.
  - It splits the object into rigid / flexible / free-swinging parts and sets each joint to match. Examples: rigid parts and held corners get 100 / level 0, flexible parts are softer, and true free hinges get torque 0.
  - It keeps the Designer's values where they already fit; your explicit wishes always win.
  - Its result is applied to the arm and shown in the chat (purple "Settings Critic" bubble). It is also reported back to the Designer for follow-ups.
  - Code: `SETTINGS_CRITIC_SYSTEM` and `settingsReview()` in `Agents.pde`. Turn it off with `"settings_critic": false`.
  - Not used for calibrated library presets or animations.
- **Torque vs stiffness explained to every agent** (`AGENT_JOINT_SETTINGS_GUIDE`, Settings Critic, tool field descriptions):
  - Any torque above 0 keeps the motor fighting back toward its angle; torque = the maximum fight-back, stiffness = how steeply it rises.
  - Even stiffness level 3 keeps the motor on. **Torque 0 is the only free hinge.**
  - Free-swinging parts (nunchuck chain, flail, rope links) must be torque 0.
